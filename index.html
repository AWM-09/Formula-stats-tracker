DATA RULES

No invented statistics. No silent zeros.

  • Missing or unavailable values are shown as “—”, not treated as zero.
  • F1 data is fetched by a scheduled build process, using the documented Jolpica API User-Agent requirement.
  • Modern F2, modern F3, GP2 and GP3 remain distinct competitions.
  • Historical coverage differs by metric; a field is not assumed to exist for every season.
  • Project-calculated records are labelled dataset-derived, not official all-time records.
